About me

I'm a full stack web developer and cybersecurity specialist. I work across the stack: Flutter and Dart for cross-platform mobile apps, Python (FastAPI), PHP (Laravel) and Node.js for back ends and REST APIs, React for dashboards, MySQL for data, and WordPress for sites that businesses can run themselves.

Security is part of how I build, not an afterthought: hashed credentials, token-based auth, input validation, output escaping and tools that help spot attacks. I also help businesses get found online through technical SEO.

I'm open to freelance work and full-time roles.
